Self-hosted fonts from google/fonts (SIL Open Font License 1.1).
Black Han Sans: https://github.com/google/fonts/tree/main/ofl/blackhansans
Kirang Haerang: https://github.com/google/fonts/tree/main/ofl/kiranghaerang
Gaegu: https://github.com/google/fonts/tree/main/ofl/gaegu

WOFF files are subsets for static app lettering and ASCII, generated with fontTools.
Body text and user content retain the system sans-serif font. If new display text is
added, regenerate the subsets from upstream TTFs with all app/components/lib text
and printable ASCII. License and copyright notices are in the adjacent OFL files.
